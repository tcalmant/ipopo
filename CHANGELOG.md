# Changelog

The release notes of iPOPO live in [`docs/changelog.md`](docs/changelog.md), so that they are
part of the documentation.

They are also published, rendered, on Read the Docs:

> https://ipopo.readthedocs.io/en/latest/changelog.html

The notes of each GitHub release are generated from that file, and every release is listed at:

> https://github.com/tcalmant/ipopo/releases

Security fixes are called out in a dedicated section of the release they ship in.
See [`SECURITY.md`](SECURITY.md) for the supported versions, how to report a vulnerability and
how to verify the integrity of a release.
